# talerka

Talerka — канструктар простых здаровых страў на сняданак, абед і вячэру з таго, што вы рэальна купляеце ў Lidl, Бядронцы і Карфуры.

Гэта статычная вэб-аплікацыя: без сервера, без зборкі, усе дадзеныя захоўваюцца толькі ў браўзеры на вашай прыладзе.

## Што ўмее першая версія

- **Дадаць прадукты**: CSV з гісторыяй пакупак, устаўлены тэкст чэка або спіс словамі («яйкі, грэчка, брокалі»). Польскія назвы з чэкаў распазнаюцца аўтаматычна; салодкае, напоі і не-ежа ў запасы не трапляюць.
- **Сёння**: тры прыёмы ежы з колцам-талеркай, выбар часу (15 хв / 30 хв / 1 гадз / запас), «гатова», «прапусціць», «з сабой».
- **Зараз**: тры стравы з таго, што ёсць, і «дакупі адно» — адна пакупка, якая найбольш паляпшае вячэру, з цаной з вашых чэкаў.
- **Тыдзень**: план на 7 дзён з улікам графіка, абедаў з сабой (учорашняя вячэра, згатаваная ўдвая) і прапушчаных прыёмаў; праверка правілаў і спіс дакупак.
- **Кошык**: долі выдаткаў па групах і тры змены з найбольшым эфектам.
- **Кухня**: тэхніка (пліта, духоўка, мікрахвалёўка…), звычайны тыдзень, час на гатаванне, чаго не ясце.
- **Дэма**: кнопка «Паспрабаваць на дэма-чэках» загружае восем выдуманых чэкаў тыповай сям'і за месяц (`js/demo.js`), каб праверыць аплікацыю без сваіх дадзеных. «Прыбраць дэма» на экране «Дадаць» вяртае ўсё як было.

## Як гэта працуе

Ядро — не рэцэпты, а 30 **шаблонаў страў** (`js/templates.js`): «база + бялок + гародніна + соус + тэкстура». У кожны слот падстаўляецца тое, што ёсць у запасах. Кожная страва мае некалькі спосабаў прыгатавання пад розную тэхніку і час.

Рухавік (`js/engine.js`) ацэньвае стравы па бялку, валакну, долі раслін на талерцы і тым, чаго не хапае на тыдні, і правярае план па сямі правілах:

| | Правіла | Мэта |
|---|---|---|
| П1 | Палова талеркі — расліны | у 70% прыёмаў |
| П2 | Бялок у кожным прыёме | ад 20 г |
| П3 | Валакно | 25 г у дзень |
| П4 | Розных раслін | 30 за тыдзень |
| П5 | Рыба / бабовыя / чырвонае мяса | 2 / 3 / не больш за 2 разы |
| П6 | Соль і цукар | кіслата і травы ў рэцэптах замест солі, без салодкіх напояў |
| П7 | Мінімум перапрацоўкі | каўбасы ў стравы не падстаўляюцца |

Аснова правілаў — Talerz Zdrowego Żywienia (NIZP-PZH), Harvard Healthy Eating Plate, рэкамендацыі WHO і парасонавыя агляды 2024–2025 гадоў.

## Запуск

```sh
npm start        # http://localhost:8000
npm test         # тэсты рухавіка (Node 20+)
```

## Размяшчэнне на GitHub Pages

Settings → Pages → Source: *Deploy from a branch*, Branch: `main`, папка `/ (root)`. Праз хвіліну аплікацыя будзе на `https://dimavak.github.io/talerka/`.

## Прыватнасць

Чэкі і запасы захоўваюцца ў `localStorage` браўзера і нікуды не адпраўляюцца. Не кладзіце файлы з уласнымі чэкамі ў гэты рэпазіторый, калі ён публічны: `*.local.csv` ужо ў `.gitignore`.

## Фармат CSV

```
store,date,item_pl,qty,unit,paid_pln,category
Lidl Księcia Bolesława 1a,2026-10-26,MSC Łosoś tusza,0.776,kg,23.20,fish
```

`category`: vegetables, fruit, fish, poultry, meat, processed_meat, eggs, dairy, legumes, whole_grain, refined_grain, nuts_seeds, sweets, snacks, drinks, drinks_sugary, sauce, fats_oils, ready_meal, non_food.
